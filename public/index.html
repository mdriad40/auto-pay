Developer Integration Guide & API Reference

Complete REST API specification for integrating custom bKash payment checkout on websites and mobile apps.

REST API v1.0 JSON Payload

1. Authentication & Security Headers

Every API request requires client credentials passed as standard HTTP request headers. Both Api-Key and License-Key are generated upon registering a new project.

Header Name Type Required Description
Api-Key String Yes Your unique 32-character Project API identifier.
License-Key String Yes Secure secret license key assigned to your registered origin domain.
Project-Name String Optional Your project reference name (recorded as reference in bKash statement).
Content-Type String Yes Must be set to application/json.

2. Initiate Payment Checkout (Create Payment)

POST /api/gateway/create-payment

Sends a payment request to generate a secure bKash checkout URL. Redirect your customer to bkashURL to complete payment with OTP and PIN. 

// JavaScript (Frontend / Backend) Integration Example:
async function checkoutWithBkash() {
  const response = await fetch("/api/gateway/create-payment", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Api-Key": "YOUR_PROJECT_API_KEY",
      "License-Key": "YOUR_PROJECT_LICENSE_KEY",
      "Project-Name": "YOUR_PROJECT_NAME"
    },
    body: JSON.stringify({
      amount: "500.00",
      customerPhone: "017XXXXXXXX",
      merchantInvoiceNumber: "INV-" + Date.now(),
      callbackURL: window.location.origin + "/thankyou.html"
    })
  });

  const data = await response.json();
  if (data.bkashURL) {
    // Redirect customer to the secure bKash payment gateway
    window.location.href = data.bkashURL;
  } else {
    alert("Payment creation failed: " + (data.errorMessage || "Unknown error"));
  }
}

Expected Response (JSON):

{
  "statusCode": "0000",
  "statusMessage": "Successful",
  "paymentID": "TR0011234567890",
  "bkashURL": "https://tokenized.pay.bka.sh/checkout/payment/TR0011234567890",
  "amount": "500.00",
  "currency": "BDT",
  "merchantInvoiceNumber": "INV-1711456789000"
}

3. Payment Execution & Callback Verification

Automatic Execution

Once the customer completes the transaction on bKash, the gateway executes the payment automatically and redirects back to your registered callbackURL with payment status parameters: 

// Handling Callback on your thankyou.html page:
const urlParams = new URLSearchParams(window.location.search);
const paymentStatus = urlParams.get("status");       // "success" | "failure" | "cancel"
const paymentID = urlParams.get("paymentID");
const trxID = urlParams.get("trxID");

if (paymentStatus === "success") {
  console.log("Payment Confirmed! TrxID:", trxID, "PaymentID:", paymentID);
  // Fulfill order for customer
} else {
  console.error("Payment was not completed. Status:", paymentStatus);
}
